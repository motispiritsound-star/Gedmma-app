Wat je hier ziet. De vijftien websites in deze demo zijn nagemaakt — echte Nederlandse bedrijfssites nabootsen zonder ze bij naam te noemen — en daarna gescand met dezelfde code die in productie draait. Scores, gevonden problemen en de concept-mail komen dus uit de tool zelf, niet uit een ontwerp. Zelf opnieuw genereren: node demo/build.ts && node demo/page.ts. De opvolgstatus per lead werkt in het echte dashboard tegen SQLite; in deze losse pagina is die weggelaten.
